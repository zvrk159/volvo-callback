Marin XC40 CLI – Terms and Conditions

Last updated: 23 October 2026

1. About

Marin XC40 CLI is a private, non-commercial tool operated by Marin Deur. It is used solely by its author to access his own Volvo vehicle via the Volvo Cars APIs. It is not offered to the public.

2. Data accessed

With the user's consent via Volvo ID, the tool may read vehicle status (doors, locks, windows, tyres, fuel, odometer, trip statistics, diagnostics, warnings, location) and send remote commands (lock, honk/flash, climatisation).

3. Use and storage

Data is retrieved on demand, displayed to the user, and not stored except for OAuth tokens kept locally on the user's own computer. No data is sold, shared with or transferred to third parties.

4. Revoking access

Access can be revoked at any time in the Volvo ID account settings.

5. Disclaimer

The tool is provided "as is", without warranty. It is not affiliated with or endorsed by Volvo Cars.
